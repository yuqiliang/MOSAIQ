# Source attribution

Every MOSAIQ release must cite the exact source data records, not only the
associated journal articles.

| Dataset | Source record | Required release treatment |
| --- | --- | --- |
| ISD | Mitchell et al., International Soundscape Database, Zenodo, doi:10.5281/zenodo.10672568 | Cite the exact version used and retain source attribution. |
| ARAUS | Ooi et al., Affective Responses to Augmented Urban Soundscapes, NTU Research Data, doi:10.21979/N9/9OTEVX | Cite the data record and article; retain upstream per-file attribution and terms. |
| SATP | Soundscape Attributes Translation Project, Zenodo, doi:10.5281/zenodo.7143599 | Cite the exact data record and retain CC BY attribution. |
| DeLTA | Mitchell et al., Deep Learning Techniques for noise Annoyance detection, Zenodo, doi:10.5281/zenodo.7158057 | Cite the data record and describe its derivation from ISD where required. |

The public deposit must add source-version dates, archive checksums, creators,
and any file-specific notices discovered during the final rights review.
