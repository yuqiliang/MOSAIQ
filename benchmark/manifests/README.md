# Frozen benchmark manifests

These CSV files are generated by `scripts/build_benchmark_report.py`. There is
one manifest for every task/dataset pair in MOSAIQ Benchmark v0.1.

Each row records:

- freeze, benchmark, task, and split versions;
- dataset and `clip_id` identity;
- assigned partition or fold;
- source table path; and
- a SHA-256 digest of the complete source clip row.

`manifest_checksums.sha256` locks the generated manifest files. Do not edit a
manifest manually. Change the source data, task contract, exclusions, split, or
release declaration and regenerate instead.

```bash
uv run python scripts/build_benchmark_report.py
uv run python scripts/build_benchmark_report.py --check-only
```
