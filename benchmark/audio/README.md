# MOSAIQ audio track

The audio track materialises rights-cleared waveforms outside Git and keeps
only source registries, manifests, quality-control outputs, configurations, and
validators in the repository.

The first implementation target is the ISD Zenodo record:

- record: <https://doi.org/10.5281/zenodo.10672568>
- source version: `1.0.1-alpha.1`
- declared licence: CC BY 4.0
- waveform format: approximately 30-second, 32-bit floating-point binaural WAV
- current stage: frozen 820-clip reference-baseline cohort

This does not make ARAUS, SATP, or DeLTA audio available and is not an ARAUS
CNN reproduction. Any ARAUS-style architecture trained on ISD must be labelled
as an adapted baseline.

## Frozen audio v0.1.0

Seven benchmark-candidate archives were verified and mapped. The accepted
cohort contains 546 train, 154 development, and 120 test clips. The committed
audio track includes QC, descriptors, clip- and response-level Target Mean and
Ridge results, cluster-bootstrap uncertainty, paired comparisons, and two
model cards. See `isd_audio_report_v0.1.0.md`.

## Storage boundary

Raw archives and extracted waveforms are stored under the project working
directory, currently:

```text
benchmark/audio/ISD/
├── archives/
├── extracted/
└── reports/
```

This path is outside the Git repository. The repository stores:

- `benchmark/governance/isd_zenodo_source_registry.csv`;
- `benchmark/audio/manifests/`;
- `benchmark/audio/qc/`;
- `benchmark/audio/configs/`;
- `benchmark/audio/audio_manifest.schema.yaml`.

## Groningen smoke workflow

```bash
uv run python scripts/acquire_isd_audio.py \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --file "ISD v1.0 Data.csv" \
  --file "ISD v1.0 Metadata.xlsx" \
  --file "WAV_Groningen_1.zip" \
  --extract

uv run python scripts/build_isd_audio_manifest.py \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --archive "WAV_Groningen_1.zip" \
  --output benchmark/audio/manifests/isd_groningen_audio_manifest.csv \
  --summary benchmark/audio/manifests/isd_groningen_audio_summary.yaml

uv run python scripts/validate_audio_manifest.py \
  benchmark/audio/manifests/isd_groningen_audio_manifest.csv

uv run python scripts/run_audio_qc.py \
  --manifest benchmark/audio/manifests/isd_groningen_audio_manifest.csv \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --output benchmark/audio/qc/isd_groningen_audio_qc.csv \
  --summary benchmark/audio/qc/isd_groningen_audio_qc_summary.yaml
```

The smoke manifest is intentionally allowed to report missing or duplicate
source assets. A public/full audio freeze must either pass
`validate_audio_manifest.py --require-complete` or publish a versioned
QC-passing cohort and explicit exclusions generated by
`freeze_isd_audio_cohort.py`. Source files that do not exist cannot be silently
treated as complete coverage.

## Full reference workflow

After acquiring the seven archives listed in
`configs/isd_audio_track.yaml`, run:

```bash
uv run python scripts/build_isd_audio_manifest.py \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --archive WAV_Granada_1.zip --archive WAV_Groningen_1.zip \
  --archive WAV_London_1.zip --archive WAV_London_2.zip \
  --archive WAV_London_3.zip --archive WAV_London_4.zip \
  --archive WAV_Venice_1.zip \
  --output benchmark/audio/manifests/isd_audio_manifest_v0.1.0.csv \
  --summary benchmark/audio/manifests/isd_audio_summary_v0.1.0.yaml

uv run python scripts/run_audio_qc.py \
  --manifest benchmark/audio/manifests/isd_audio_manifest_v0.1.0.csv \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --output benchmark/audio/qc/isd_audio_qc_v0.1.0.csv \
  --summary benchmark/audio/qc/isd_audio_qc_summary_v0.1.0.yaml

uv run python scripts/freeze_isd_audio_cohort.py \
  --manifest benchmark/audio/manifests/isd_audio_manifest_v0.1.0.csv \
  --qc benchmark/audio/qc/isd_audio_qc_v0.1.0.csv \
  --output-dir benchmark/audio/cohort/v0.1.0

uv run python scripts/extract_audio_descriptors.py \
  --manifest benchmark/audio/manifests/isd_audio_manifest_v0.1.0.csv \
  --storage-root "/path/to/benchmark/audio/ISD" \
  --output benchmark/audio/features/isd_audio_descriptors_v0.1.0.csv \
  --summary benchmark/audio/features/isd_audio_descriptors_summary_v0.1.0.yaml

uv run python scripts/run_isd_audio_baselines.py \
  --descriptors benchmark/audio/features/isd_audio_descriptors_v0.1.0.csv \
  --output-dir benchmark/audio/results/v0.1.0

uv run python scripts/evaluate_isd_audio_baselines.py \
  --predictions benchmark/audio/results/v0.1.0/predictions.csv \
  --output-dir benchmark/audio/results/v0.1.0/evaluation \
  --iterations 2000 --seed 20260730

uv run python scripts/build_isd_audio_model_cards.py \
  --results-dir benchmark/audio/results/v0.1.0 \
  --output-dir benchmark/audio/model_cards/v0.1.0

uv run python scripts/validate_isd_audio_outputs.py
```

## Leakage rule

The same waveform, canonical audio asset, or source GroupID must never cross
train, development, and test partitions. Response-level records inherit the
split of their linked `clip_id`; multiple participant responses to the same
recording are never split independently.
