# MOSAIQ external usability review protocol

This protocol operationalises the OMAIB commitment to a lightweight review by
Connected Places Catapult, end users, or an independent soundscape researcher.
It is ready to run but has not yet been completed.

## Reviewer task

Using only the archived release and its documentation, the reviewer should:

1. install the locked environment;
2. validate all four data packages;
3. identify the eligible records for one task;
4. reproduce one deterministic baseline;
5. create and validate one results submission;
6. locate the licence and attribution rule for one source record;
7. explain one known limitation without contacting the authors.

## Acceptance criteria

- All six executable actions complete without undocumented intervention.
- Reproduced metrics and checksums match the archive.
- The reviewer can distinguish clip-level from response-level tasks.
- The reviewer does not infer that audio or visual models are included.
- The reviewer can identify the ARAUS rights-review block and ISD exclusions.
- Every critical ambiguity is logged with severity and proposed correction.

## Record

The completed review should record reviewer role, date, release DOI/commit,
platform, elapsed time, commands run, pass/fail results, and issue links. The
reviewer should not be an author of the benchmark implementation.
